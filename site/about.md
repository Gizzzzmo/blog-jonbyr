Hey there, I'm Jonas 👋 welcome to my blog.

I'm a programmer, working professionally on embedded systems. I love to think
and talk about everything low-level-programming, compilers, formal verification,
maths, (and probably a bunch of other things) and I'm hoping to share of some of
the things I find interesting here.

**About this site**

This site is created by a pretty jank markdown-to-html converter I (had an LLM)
built. It's a patchwork of pandoc lua-filters, python, and some C. It's not
public, but the markdown code and the html-jinja-templates that go into the
builder you can view [here](https://blog-git.jonbyr.com).

Each version of this entire site corresponds to one commit in that git repo (but
not every commit always has a published website), and you can always browse any
older version of the site under `<commit-hash>-blog.jonbyr.com`. Hope there is
(or soon will be) something you find interesting.
